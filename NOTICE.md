# Acknowledgments

AgentMeter is inspired by [CodexBar](https://github.com/steipete/CodexBar), an MIT-licensed macOS utility for viewing AI coding service usage. CodexBar helped establish the idea of showing provider quota windows alongside account information.

AgentMeter's implementation, interface, and three-meter icon are independently authored. This distribution does not include CodexBar source code or artwork. AgentMeter has no third-party runtime dependencies.

Codex, OpenAI, Claude, Anthropic, TRAE, Doubao, and other product names belong to their respective owners. AgentMeter is an independent project and is not affiliated with or endorsed by those providers. References identify compatible services.

The experimental TRAE SOLO CN adapter independently implements a local credential format and an internal personal-account usage request. It does not include vendor source code, represent an official SDK, or use TRAE Enterprise OpenAPI.

AgentMeter is distributed under the [MIT License](LICENSE).
